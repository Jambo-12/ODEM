# Local model layout

Preprocessing expects model files to be stored directly in this repository.

```Shell
models/
├── Qwen2.5-VL-7B-Instruct/
│   ├── config.json
│   └── ...
└── ViCLIP/
    └── ViClip-InternVid-10M-FLT.pth
```

Place the model files at the paths above before running a preprocessing
command.
